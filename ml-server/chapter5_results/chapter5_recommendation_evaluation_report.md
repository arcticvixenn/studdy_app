## 6. Інтерпретація

Оцінювання рекомендаційної системи виконано на контрольному наборі навчальних матеріалів і змодельованих взаємодій користувачів. Popularity baseline використовується як найпростіший варіант порівняння, content-based підхід враховує текстову схожість матеріалів, а hybrid ML підхід поєднує схожість контенту, популярність, збіг теми та складність матеріалу. Порівняння цих підходів дозволяє показати, чи дає ML-логіка кращий результат порівняно з простими правилами.
